# 🏨 Node.js Hotel API

A simple backend API for hotel management built with Node.js and Express.

## 🚀 Built With

- JavaScript
- Node.js
- Express

## ⚙️ Getting Started

1. Clone the repository:
```bash
git clone https://github.com/elisheva-dev/NodeProject-Hotel.git
```
2. Install dependencies:
```bash
npm install
```
3. Run the server:
```bash
node index.js
```

## 📌 Features
- RESTful API structure
- CRUD operations for hotel data
- Organized with Controllers, Models, and Routers
